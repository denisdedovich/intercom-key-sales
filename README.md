# Учет продажи ключей для домофонов

Веб-приложение для учета продажи ключей для домофонов и аудиотрубок в квартирах.

## Функциональность

- Управление списком домов (добавление, редактирование, удаление)
- Таблица квартир с информацией о жильцах
- Учет проданных ключей
- Отслеживание статуса оплаты (наличные/перевод)
- Учет выставленных счетов
- Статус установки трубки (установлена/требуется покупка)
- Оплата трубки
- Общая информация о доме (количество квартир, подключенных, абонплата)

## Технологии

- **Frontend**: React.js
- **Backend**: Node.js + Express
- **Хранение данных**: JSON файл

## Запуск

### Сервер

```bash
cd server
npm install
npm start
```

Сервер запускается на порту 3001.

### Клиент

```bash
cd client
npm install
npm start
```

Клиент запускается на порту 3000 и проксирует API запросы на сервер.
