## 24.06.2026

### Исправления таблицы (коммит 27e4c53)
- **colSpan** в пустом состоянии таблицы был на 1 больше нужного (10 → 9)
- **Мёртвый код** удалён: `{rawColumns.length === 0 && rawColumns.map(...)}` — никогда не рендерился
- **Raw-колонки** теперь отображаются как отдельные редактируемые ячейки вместо схлопнутой одной ячейки
- Убрано условие `idx === 0` для raw-колонок — данные отображаются для каждого жильца

### Красивый список домов + автогенерация квартир (коммит 1682447)
- **HouseList.jsx** — новый компонент: карточки домов вместо выпадающего select
- Карточки показывают: адрес, абонплата/мес, подключено, квартир в базе
- **Автогенерация квартир**: при POST /api/houses создаётся `totalApartments` квартир с нумерацией 1..N
- Кнопка "← Назад к списку" при просмотре дома

### Поле «Договор» + автоподсчёт «Подключено» (коммит 1682447)
- Новая колонка **«Договор»** (hasContract) — чекбокс у каждого жильца
- **Подключено** считается автоматически: количество квартир, где хотя бы один жилец имеет `hasContract: true`
- Поле `connectedApartments` больше не ручное — вычисляется на фронте

## Убран столбец «Договор» (коммит 4696024)
- Убран отдельный столбец «Договор» (our hasContract) из таблицы
- «Подключено» теперь считается по raw-столбцу «наличие договора» из импортированных данных (= "+" → подключена)

---

## Базовая таблица — столбец «Договор» (коммит 0987202)
- Добавлен столбец **«Договор»** после ФИО с select «Подписан / Не подписан»
- Новое поле `contractStatus` (`'signed'` / `'unsigned'`) в модели жильца
- **Подключено** считается по **обоим источникам**:
  - rawData «наличие договора» === '+' (импорт)
  - contractStatus === 'signed' (базовая таблица)
- Сервер: `POST /residents` принимает `contractStatus`

## Переработка таблицы под Excel-формат (коммит f5a7e49)
- Таблица теперь показывает **только столбцы из импортированного файла** + «Действия»
- **Убраны**: Кв., ФИО, Ключи, Оплачен, Договор, Способ оплаты, Счет, Статус трубки, Оплата трубки
- Каждая строка = одна квартира с raw-данными из файла
- Упрощённый компонент: только `renderRawCell` + кнопки

## Исправление столбцов таблицы (коммит — текущий)
- **Сервер**: при импорте собираются **все уникальные ключи** из всех строк (а не только из первой)
- **database.json**: обновлены `columns` для дома «МЖ1Д» — теперь все 12 столбцов из Excel
- **Клиент**: фоллбэк — если `house.columns` пустой, колонки определяются из `rawData` квартир
